Connect Shared Database
One-time setup · Takes 5 minutes · Free forever
Once connected, all team members share the same live data — tasks, NOCs, notifications sync in real time across all devices.
1
Go to supabase.com → Sign up free (use GitHub or Google) → Create a new project → give it any name (e.g. "teamflow-cdmsmith")
2
After the project loads → click Project Settings (gear icon) → API → copy your Project URL and anon public key
3
Go to SQL Editor in Supabase → click New Query → paste and run the setup SQL (click the copy button below)
CREATE TABLE IF NOT EXISTS tf_data (key text PRIMARY KEY, value jsonb, updated_at timestamptz DEFAULT now());
4
Run this SQL to disable row-level security (public tool): ALTER TABLE tf_data DISABLE ROW LEVEL SECURITY;
